# 停用的形象包

这里的包不会被自动发现（`packs.ts` 只扫 `builtin/*/manifest.json`），
也不会出现在设置面板的可选列表里。留着是为了不丢素材。

## default（绿色小团子）

2026-10-31 停用。用户原话：「不要这个绿色的脸，不管是灯条还是气泡，都要小机器人」。

这套包只有一张绿色圆脸 + 天线，缩到 30–40px 后五官糊成一团，在灯条上尤其明显。
换成 `builtin/robot`（白色小机器人：天线、护目镜、手、脚都在）后同一尺寸下可读性
好得多，也才是用户想要的那个角色。

要恢复：把 `default/` 移回 `src/buddies/builtin/`，并清掉设置里的 `buddy_pack`。
