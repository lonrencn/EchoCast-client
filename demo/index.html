ARCHITECTURE / 双向长连

任何网络节点，
任何登记客户端

服务端可以落在任何能被访问的网络位置 —— 公网网关、内网主机、云上容器、甚至一台出差途中的笔记本。 每一台登记过的终端都握着一条双向长连：任务帧下行， 进度、回执、问询答复上行 —— 所有任务尽在掌握。 点右侧桌面里任何一台终端试试。

下行 · 任务帧 上行 · 进度 / 回执 / 答复
01 / QUIET

常驻，但不打扰

通知浮出后不自动消失：悬停 10 秒渐隐已读，或点「已读」立刻收起；没看到的挤进「还有 N 条」，随时展开回看。

02 / ASK

问询常驻可忽略

任务中途需要人拍板时，问询气泡一直等你：点「继续 / 先不了」回传服务端，或点「忽略」先放一边，不响应也绝不丢。

03 / MEDIA

结果带附件

图表、音频、文件随通知直达。客户端预取进本地缓存，断网也能回看，点开即放大预览。

04 / BUDDY

形象可换

气泡里的小机器人是可替换的形象包（WebP 帧组 + manifest）。随包的 buddy-forge 管线可以定制你自己的角色。
