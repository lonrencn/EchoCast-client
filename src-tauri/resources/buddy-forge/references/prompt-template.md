# 形象提示词模板

## 主模板

```
【角色】{species}小生物，主色{color}，钝角造型，简笔扁平插画
【动作】{action}
【构图】正面全身，主体占画面 75%，水平居中，脚底贴齐画面下沿
【风格】扁平矢量，2px 深色描边，纯色填充；无渐变、无投影、无高光、无地面阴影
【背景】纯洋红 #FF00FF 平涂，无纹理
【禁止】文字、水印、多余装饰；颜色不超过 3 种
【尺寸】1024x1024
```

模板里每条都不是装饰，删了会出问题：

- **钝角造型**：避免模型画出尖刺、闪亮眼睛、渐变高光那套廉价 3D 感
- **纯洋红平涂**：白底会被角色自身的白色吃掉，绿幕会被绿色角色吃掉，洋红几乎不参与角色配色
- **2px 深色描边**：没有描边的平涂角色在浅色气泡上会糊成一片
- **颜色不超过 3 种**：色数一多，缩到 40px 后就变成噪点
- **无投影**：投影会和气泡自身的 1px 描边打架，且抠图后变成黑边

## 六个动作

| 状态 | 动作描述 | 情绪 |
|---|---|---|
| idle | 正面站立，微微抬头，睁眼平视，嘴角轻抿 | 待命，平静 |
| idle_blink | 正面站立，双眼闭合，神情平静 | 眨眼用，只换眼睛 |
| hover | 抬头看向上方，笑眼弯起，一只手向侧面半抬 | 被注意到 |
| success | 笑眼弯成弧形，张嘴笑，一只手向上举起 | 完成，但别太夸张 |
| fail | 低头，肩膀下垂，眼睛下垂，嘴角平直 | 沮丧，不要哭 |
| sleep | 蜷缩身体，闭眼，头微微低垂 | 久等，困了 |

**表达姿态要改形状，不要改位置**：想画「沮丧」不要写「身体下移」，那会被裁切对齐抹平；要写「身体变矮、肩膀下垂、嘴角下弯」。

**举手不要高过头顶太多**：缩放按 bbox 取小值，手举太高会让这一帧整体变小，串起来看像在缩放抖动。

## 风格变体

`{species} × {color}` 两轴组合，建议先出 4 套试色：

| species | 形态描述 |
|---|---|
| 方糖形 | 圆角矩形身体，短天线，比例敦实 |
| 豆形 | 竖向椭圆，无明显四肢，靠两只小脚站立 |
| 毛球 | 圆形带绒毛边，眼睛大，无嘴 |

| color | 主色 / 强调 |
|---|---|
| 苔绿 | `#6E7F5C` / `#B26A45` |
| 陶土 | `#B26A45` / `#6E7F5C` |
| 靛蓝 | `#3C5C8C` / `#B26A45` |
| 暖砂 | `#C8A67A` / `#5C4634` |

## 风格 B：3D 哑光小机器人（内置 robot 包同款）

扁平矢量之外的另一套已验证风格，角色描述串全程复用：

```
【角色】一只圆润可爱的 3D 卡通小机器人：白色哑光陶瓷质感外壳，
护目镜式深色屏幕脸（表情画在屏幕里），头顶一根短天线，
圆角关节的短手短脚，比例敦实，钝角无尖刺
【动作】{action}
【构图】正面全身，主体占画面 75%，水平居中，脚底贴齐画面下沿
【风格】柔和 3D 渲染，哑光材质；无高光反射、无景深、无背景道具、无地面阴影
【背景】纯洋红 #FF00FF 平涂，无纹理
【禁止】文字、水印；整体配色不超过 3 种（白 + 屏幕深色 + 一点强调色）
【尺寸】1024x1024
```

注意与扁平模板的差异：**哑光必须显式写**（3D 模型默认会加高光，抠图后高光边缘留白点）；
「无景深、无背景道具」也要写，否则 3D 风格外溢。

其余动作复用同一张 idle 做图生图，开头写「保持原图中这只小机器人的外形、比例、材质、配色完全一致，只改为……」。

## 生图参数

- 尺寸 1024×1024，`quality: high`（低质量会把 2px 描边糊掉，抠图后边缘发毛）
- 若模型支持 `background: transparent`，可以开启，管线会自动跳过色键——但不要在提示词里写「透明」
- 同一套六个动作**用同一条角色描述的字符串**，只换动作那一行，否则会长成六只不同的生物

## 常见失败

| 现象 | 修法 |
|---|---|
| 画了棋盘格假透明 | 模板里删掉「透明」字样，只写「纯洋红平涂」 |
| 角色带地面阴影 | 「无地面阴影」重复一遍，并加「脚底直接接触画面下沿」 |
| 六张画风不一致 | 固定同一 seed，或把第一张作为 reference 图做 image-to-image |
| 眼睛里有高光点 | 加「哑光眼球，无高光反射」 |
